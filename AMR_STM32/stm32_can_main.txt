좋아, 이제 구조는 완전히 잡혔으니까
**STM32 #2 (수신 보드)**를

> CAN으로 IMU 값 수신 → UART로 PC(시리얼 모니터)에 뿌리는 노드

로 만들자.

이미 STM32 #1(보내는 쪽)에서
**CAN: 250kbps, PD0/PD1, SN65HVD230** 세팅까지 해둔 상태를 그대로 따라가면 돼.

---

## 1. 하드웨어 세팅 정리

### 1) CAN 배선 (STM32 #2 ↔ SN65HVD230)

STM32F407G-DISC1 보드 핀 기준으로:

* **CAN1_RX = PD0 (AF9)**
* **CAN1_TX = PD1 (AF9)**

SN65HVD230 모듈과 연결:

| SN65HVD230 | STM32F407G-DISC1 #2 |
| ---------- | ------------------- |
| VCC        | 3.3V                |
| GND        | GND                 |
| TXD (D)    | **PD1 (CAN1_TX)**   |
| RXD (R)    | **PD0 (CAN1_RX)**   |
| RS         | GND                 |
| CANH       | CAN 버스 CANH         |
| CANL       | CAN 버스 CANL         |

두 STM32 보드 사이:

* CANH ↔ CANH
* CANL ↔ CANL
* GND ↔ GND
* 버스 양 끝 보드에만 CANH–CANL 사이 **120Ω** 종단저항 1개씩 (총 2개 → 측정 시 약 60Ω)

### 2) UART 출력 (시리얼 모니터로 보기)

STM32F4DISCOVERY/STM32F407G-DISC1 보드는

* USART2 TX = **PA2**
* USART2 RX = **PA3**
* 이게 ST-LINK USB를 통해 PC로 가는 **Virtual COM 포트**로 연결되어 있음.

즉, **CN5(USB ST-LINK)**를 PC에 연결하고
PC에서 해당 COM 포트를 115200bps로 열면 UART2 메시지가 보인다.

---

## 2. CubeMX / CubeIDE 설정 (수신 보드)

새 프로젝트를 만든다고 가정하고 정리할게.

### 2-1. 기본 프로젝트

1. **Board Selector** → `STM32F407G-DISC1` 선택
2. Toolchain: STM32CubeIDE

### 2-2. Clock

* `Clock Configuration` 탭에서:

  * SYSCLK = 168 MHz
  * APB1 = 42 MHz (기본 값이면 그대로)

(보내는 보드와 똑같이 맞춰야 CAN 속도가 정확히 일치함)

### 2-3. CAN1 설정

1. **CAN1**를 활성화:

   * Pinout & Configuration → Connectivity → CAN1 → Mode: **Normal**

2. 핀 매핑:

   * CAN1_RX → **PD0**
   * CAN1_TX → **PD1**
     (CubeMX가 자동으로 **AF9**로 설정해준다.)

3. Parameter Settings (bit timing) – 250 kbps:

* Prescaler: **12**
* Time Quanta in Bit Segment 1: **11**
* Time Quanta in Bit Segment 2: **2**
* Resynchronization Jump Width: **1 Time Quantum**

APB1=42MHz에서:

> Bitrate = 42MHz / (12 × (1+11+2)) = 42e6 / (12×14) = **250 kbps**

나머지 옵션:

* Mode: Normal
* Auto Bus-off: Enable
* Auto Retransmission: Enable
* etc… 기본값 그대로 두면 OK.

### 2-4. UART2 설정

1. Pinout → USART2 → Asynchronous
2. TX = PA2, RX = PA3
3. Parameter Settings:

   * BaudRate: **115200**
   * 8-N-1 (8bit, No parity, 1 stop bit) 기본값

## 3. 수신 보드 코드 설계

**목표 동작**

* CAN ID **0x100**으로 들어오는 6바이트 프레임 수신

* 내부 포맷: ESP32/STM32 발신과 동일

  ```text
  data[0..1] : yaw(heading) * 100 (int16_t, little-endian)
  data[2..3] : roll * 100
  data[4..5] : pitch * 100
  ```

* 이를 다시 float(°)로 환산 → `"H:xx.xx,R:yy.yy,P:zz.zz\r\n"` 형식으로 UART 송출

아래 코드는 CubeMX가 생성한 main.c에
**추가/수정해야 하는 USER CODE 부분**만 포함한 예제야.

---

## 4. main.c: 전역 변수 & 프로토타입

```c
/* Includes ------------------------------------------------------------------*/
#include "main.h"

/* Private includes ----------------------------------------------------------*/
/* USER CODE BEGIN Includes */
#include <string.h>
#include <stdio.h>
/* USER CODE END Includes */

/* Private variables ---------------------------------------------------------*/
CAN_HandleTypeDef hcan1;
UART_HandleTypeDef huart2;

/* USER CODE BEGIN PV */

/* CAN 수신용 헤더/버퍼 */
CAN_RxHeaderTypeDef canRxHeader;
uint8_t             canRxData[8];

/* 디버깅/출력을 위한 변수 */
volatile float rx_heading_deg = 0.0f;
volatile float rx_roll_deg    = 0.0f;
volatile float rx_pitch_deg   = 0.0f;

char uart_tx_buf[128];

/* USER CODE END PV */
```

필요하면 위에 `/* USER CODE BEGIN PFP */` 쪽에 프로토타입 추가:

```c
/* USER CODE BEGIN PFP */
void CAN1_Start_AllFilter(void);
void UART_SendIMU(float heading, float roll, float pitch);
/* USER CODE END PFP */
```

## 5. CAN1 초기화 함수 (MX_CAN1_Init)

CubeMX가 자동으로 비슷하게 만들 거야.
없으면 다음처럼 작성해줘:

```c
static void MX_CAN1_Init(void)
{
  hcan1.Instance = CAN1;
  hcan1.Init.Prescaler = 12;                 // 250 kbps
  hcan1.Init.Mode = CAN_MODE_NORMAL;
  hcan1.Init.SyncJumpWidth = CAN_SJW_1TQ;
  hcan1.Init.TimeSeg1 = CAN_BS1_11TQ;        // BS1=11Tq
  hcan1.Init.TimeSeg2 = CAN_BS2_2TQ;         // BS2=2Tq (총 14Tq)
  hcan1.Init.TimeTriggeredMode = DISABLE;
  hcan1.Init.AutoBusOff = ENABLE;
  hcan1.Init.AutoWakeUp = DISABLE;
  hcan1.Init.AutoRetransmission = ENABLE;
  hcan1.Init.ReceiveFifoLocked = DISABLE;
  hcan1.Init.TransmitFifoPriority = DISABLE;
  if (HAL_CAN_Init(&hcan1) != HAL_OK)
  {
    Error_Handler();
  }
}
```

이 패턴은 ST HAL 예제와 동일한 초기화 형태야.

## 6. CAN 필터 설정 + 시작 함수

`/* USER CODE BEGIN 0 */` 부분에:

```c
/* USER CODE BEGIN 0 */

void CAN1_Start_AllFilter(void)
{
    CAN_FilterTypeDef sFilterConfig;

    // 모든 ID 수신 (Mask=0)
    sFilterConfig.FilterBank = 0;
    sFilterConfig.FilterMode = CAN_FILTERMODE_IDMASK;
    sFilterConfig.FilterScale = CAN_FILTERSCALE_32BIT;
    sFilterConfig.FilterIdHigh = 0x0000;
    sFilterConfig.FilterIdLow  = 0x0000;
    sFilterConfig.FilterMaskIdHigh = 0x0000;
    sFilterConfig.FilterMaskIdLow  = 0x0000;
    sFilterConfig.FilterFIFOAssignment = CAN_FILTER_FIFO0;
    sFilterConfig.FilterActivation = ENABLE;
    sFilterConfig.SlaveStartFilterBank = 14;  // 단일 CAN이면 14 정도로 두면 됨 

    if (HAL_CAN_ConfigFilter(&hcan1, &sFilterConfig) != HAL_OK)
    {
        Error_Handler();
    }

    if (HAL_CAN_Start(&hcan1) != HAL_OK)
    {
        Error_Handler();
    }
}

/* USER CODE END 0 */
```

> 나중에 ID 0x100만 받고 싶다면 필터를 좁힐 수 있지만,
> 지금은 일단 **모든 ID 허용**이 디버깅에 제일 편함.

## 7. UART로 IMU 값 보내는 함수

`/* USER CODE BEGIN 4 */` 부분에:

```c
/* USER CODE BEGIN 4 */

void UART_SendIMU(float heading, float roll, float pitch)
{
    int len = snprintf(uart_tx_buf, sizeof(uart_tx_buf),
                       "H:%.2f,R:%.2f,P:%.2f\r\n",
                       heading, roll, pitch);

    HAL_UART_Transmit(&huart2, (uint8_t*)uart_tx_buf, len, HAL_MAX_DELAY);
}

/* USER CODE END 4 */
```

## 8. main() 안에서 초기화 & 루프

### 8-1. 초기화 단계에서 CAN, UART 호출

`main()` 함수 안에서:

```c
int main(void)
{
  HAL_Init();
  SystemClock_Config();

  MX_GPIO_Init();
  MX_CAN1_Init();
  MX_USART2_UART_Init();   // CubeMX가 이미 생성

  /* USER CODE BEGIN 2 */
  CAN1_Start_AllFilter();  // ★ 필터 설정 + CAN Start
  /* USER CODE END 2 */

  /* Infinite loop */
  /* USER CODE BEGIN WHILE */
  while (1)
  {
    /* USER CODE END WHILE */

    /* USER CODE BEGIN 3 */

    // CAN RX FIFO에 데이터가 있는지 확인
    if (HAL_CAN_GetRxFifoFillLevel(&hcan1, CAN_RX_FIFO0) > 0)
    {
        if (HAL_CAN_GetRxMessage(&hcan1,
                                 CAN_RX_FIFO0,
                                 &canRxHeader,
                                 canRxData) == HAL_OK)
        {
            // 1) ID와 DLC 체크
            if ((canRxHeader.IDE == CAN_ID_STD) &&
                (canRxHeader.StdId == 0x100) &&      // IMU ID (보내는쪽과 동일)
                (canRxHeader.DLC  >= 6))             // yaw, roll, pitch = 6바이트
            {
                // 2) int16_t로 복원 (little-endian)
                int16_t yaw_centi   = (int16_t)(canRxData[0] | (canRxData[1] << 8));
                int16_t roll_centi  = (int16_t)(canRxData[2] | (canRxData[3] << 8));
                int16_t pitch_centi = (int16_t)(canRxData[4] | (canRxData[5] << 8));

                rx_heading_deg = yaw_centi   / 100.0f;
                rx_roll_deg    = roll_centi  / 100.0f;
                rx_pitch_deg   = pitch_centi / 100.0f;

                // 3) UART로 전송
                UART_SendIMU(rx_heading_deg, rx_roll_deg, rx_pitch_deg);
            }
        }
    }

    // 너무 바쁘지 않게 살짝 쉼 (선택)
    HAL_Delay(1);

  }
  /* USER CODE END 3 */
}
```

여기서 사용한 HAL 함수들 (`HAL_CAN_GetRxFifoFillLevel`, `HAL_CAN_GetRxMessage`, `HAL_CAN_AddTxMessage` 같은 패턴)은
ST HAL CAN 예제 및 레퍼런스에 그대로 나오는 표준 사용법이야.

## 9. 테스트 방법

1. **STM32 #1 (보내는 보드)**

   * 앞에서 만든 코드: BNO055 → Euler(heading/roll/pitch) 읽어서
   * CAN ID 0x100, 6바이트 프레임으로 주기적으로 송신.

2. **STM32 #2 (수신 보드)**

   * 방금 만든 코드 빌드 & 다운로드.
   * USB ST-LINK(CN5)를 PC에 연결 → PC에서 해당 COM 포트 115200bps 오픈.

3. 두 보드 CANH/CANL/GND 연결, 종단저항 확인 후 모두 전원 ON.

4. 기대 동작:

   * PC 시리얼 모니터에
     `H:123.45,R:1.23,P:-4.56`
     형식 로그가 계속 출력.
   * 보드 #1을 움직이면, 보드 #2 콘솔에서도 값이 같이 변하는지 확인.

## 10. 다음 확장 아이디어 (간단 힌트)

* **필터 최적화**:
  나중에 센서 노드가 늘어나면, 수신 보드에서

  * ID 0x100 → IMU
  * ID 0x110 → 초음파
  * …
    이런 식으로 분기하고, 필터도 해당 ID만 통과시키도록 좁히면 CPU 부담 감소.

* **인터럽트 기반 수신**:
  지금은 폴링 방식이지만,
  `HAL_CAN_ActivateNotification()` + `HAL_CAN_RxFifo0MsgPendingCallback()`을 쓰면
  수신 콜백 안에서 바로 파싱 → 메인 루프는 다른 일에 집중하도록 설계 가능.

---

이대로 구현하면

> STM32 #1: BNO055 → CAN(0x100, yaw/roll/pitch) 전송
> STM32 #2: CAN 수신 → float 복원 → UART2로 PC 출력

구조가 끝까지 연결돼.
코드에서 막히는 부분(컴파일 에러, HAL 함수 사용 등) 생기면 에러 메시지랑 main.c 올려주면 거기부터 같이 잡아보자.
